# Security and private data

Report suspected vulnerabilities in **STPG_RP2350_LA** privately through this
repository's **Security → Advisories → Report a vulnerability**. If the option
is not available, ask the maintainer for a private reporting channel without
sharing any details publicly. Do not open a public issue for a vulnerability.

The companion runs locally. Do not expose its browser interface to a public
network. Use only trusted analyzer bindings and accessory configurations.
Capture plans, configuration files, run directories, waveforms, logs and
screenshots may contain confidential information. Reproduce public bug
reports with synthetic input and remove local paths, serial numbers and tokens.
