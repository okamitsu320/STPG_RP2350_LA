Getting started

This tool sets up the analyzer and reads its captures. It never runs the STPG: a capture happens during a run started in the STPG Runner (stpg-view), which starts this tool's accessory process for that run. The Runner's Analyzers… list only shows what you save here.

  1. Register the analyzer (card 1, Add binding…): press Scan ports and Use on the analyzer's own row (nothing is selected for you), choose the firmware limits of the analyzer firmware you installed, choose the wiring, and Save.
  2. Check it: press Identify. It opens only that port, asks for its identity and closes it. If the analyzer reports other limits, review them and Save them yourself; nothing is changed until you do.
  3. Wire it as the binding's Wiring table shows, with a common ground.
  4. Plan (cards 2 and 3): open the bundle (the same one as in the Runner) and plan a capture around a vector.
  5. Write the run config (card 4): this makes a new folder with external.json.
  6. Run in the STPG Runner: in its External accessory card choose that external.json, press Check, tick “use with the next run” and press Run….
  7. See the capture (card 7): open the run's folder to see the capture, its alignment and the waveform.

Without an analyzer, card 5 makes a mock capture from a plan or imports a .lac or CSV file.

Writes a new folder with external.json (the program to start, the binding and the plan, with their SHA-256). In the STPG Runner, choose that file in the External accessory card, press Check and tick “use with the next run”. The Runner then starts this tool's accessory process for that run only: it arms the analyzer right before the target segment's RUN and keeps the capture in the run's accessory/capture/ folder.
